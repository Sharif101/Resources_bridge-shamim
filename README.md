## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Sharif101/Resources_bridge-shamim.git
cd Resources_bridge-shamim
npm install
npm start
```

The application will run on:
http://localhost:5173

# How the App Works

React Router handles nested and dynamic routes

Example:
/dashboard/inventory/inv001
Context API manages authentication and UI state
Tailwind CSS + shadcn/ui are used for a modern, consistent design
Mock inventory data is used where backend APIs are not yet available
